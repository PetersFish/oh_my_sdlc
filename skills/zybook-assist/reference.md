# zybook-assist 参考

## 考点题型常见变体与 Mental Model

| 变体类型 | 典型问法 | Mental Model 要点 |
|----------|----------|-------------------|
| 时间/空间复杂度 | 分析某操作的最坏/平均复杂度 | 先确定规模 n 是什么 → 看循环/递归层数与每层代价 → 写递推或直接给出 O(...) |
| 手写伪代码 | 实现某算法或某一步 | 先写不变式或边界条件 → 按教材/课堂给出的骨架填关键步骤 → 注意终止条件 |
| 选择数据结构 | 「用哪种结构更合适」或「比较 A 与 B」 | 从操作频次（读/写/混合）、规模、是否要求有序等列出约束 → 对照各结构的权衡 → 给出选择并简述理由 |
| 图示/构造题 | 给定操作序列，画图或标出某步后的状态 | 严格按定义一步步执行，每步后检查不变量（如平衡因子、堆序性）再进入下一步 |

出题时常用变体：改一个条件（如「若改为…则选谁」）、给代码找错、给执行过程填中间状态。预测时优先覆盖「本章强调的不变量 + 与同类结构的对比」。

## 术语表写作要点

- **直观类比**：用生活中或已学概念作比，一句话即可；避免再用抽象术语解释抽象术语。
- **典型应用场景**：写「在什么系统/问题里会用到」，可具体到「数据库 B+ 树索引」「LRU 缓存」等，便于与系统设计挂钩。
- 只收**本章核心**术语（算法名、关键概念、易混词），不穷举生词；若用户需要某词加入术语表，可单独补充。
