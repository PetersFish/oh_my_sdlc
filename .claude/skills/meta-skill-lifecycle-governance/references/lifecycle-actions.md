# Lifecycle Actions

- `DEVELOP`: modify the canonical skill repo.
- `EVALUATE-IN-REPO`: validate the skill in the repo before release.
- `PILOT-IN-PROJECT`: install a candidate skill into a real project for validation.
- `ITERATE-FROM-PROJECT`: improve a stable installed skill from real project use.
- `BACKPORT`: promote only generic improvements into the canonical repo.
- `RELEASE`: version and tag a stable skill.
- `DISTRIBUTE`: install a stable release to selected AI CLI targets.
