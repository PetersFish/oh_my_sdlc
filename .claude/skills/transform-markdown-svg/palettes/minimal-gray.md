# Minimal Gray

Use for architecture diagrams, engineering module maps, algorithm flows, and system relationship diagrams where a calm technical feel is preferred.

Keywords: minimal, cool, engineering, premium.

## Colors

| Role | Color | Usage |
|---|---:|---|
| Background | `#FAFAFA` | Page or canvas background |
| Primary node | `#4A5568` | Main logic |
| Secondary node | `#CBD5E0` | Ordinary node |
| Emphasis node | `#2563EB` | Current step, important focus |
| Success node | `#16A34A` | Completed state |
| Warning node | `#DC2626` | Exception or warning |
| Edge | `#6B7280` | Main and secondary connectors |
| Text | `#111827` | Default text |

## Style

- Border: `1px`
- Radius: `6px`
- Shadow: off
- Whitespace: generous
- Node spacing: wide
- Main edges: solid
- Auxiliary edges: dashed
