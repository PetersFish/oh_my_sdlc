# Muted Morandi

Use for math notes, derivation relationship diagrams, knowledge structures, and long-reading study diagrams where visual pressure should be low.

Keywords: soft, premium, restrained, comfortable.

## Colors

| Role | Color | Usage |
|---|---:|---|
| Background | `#F6F7F8` | Page or canvas background |
| Primary node | `#6B7280` | Ordinary concept |
| Secondary node | `#A1A1AA` | Supporting concept |
| Emphasis node | `#D97706` | Important step |
| Success node | `#059669` | Conclusion |
| Warning node | `#B91C1C` | Conflict, contradiction, counterexample |
| Edge | `#475569` | Fine connectors |
| Text | `#1F2937` | Default text |

## Style

- Border: `1px`
- Radius: `10px`
- Shadow: optional, very subtle only
- Edge width: `1.5px`
- Overall saturation: low
