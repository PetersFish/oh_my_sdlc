## Issues

- `scripts/sync_derived_artifacts.py` does not satisfy Task 3 Step 3. Incremental fix mode classifies a deleted skill path as an affected skill and `_skill_fix_steps()` blindly creates `install_skill.py` commands for that missing canonical skill directory. The plan requires validating affected skill directories during fix, not blindly calling `install_skill.py` against a missing source directory, and including the missing skill name in the report/error path.
- Existing tests cover modified/added skill paths but do not cover deleted/renamed skill paths, so this requirement gap is not executable-verified.
