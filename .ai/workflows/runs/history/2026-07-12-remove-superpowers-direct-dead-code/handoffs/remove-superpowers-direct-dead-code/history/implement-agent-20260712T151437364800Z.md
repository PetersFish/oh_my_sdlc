## Learnings

- When a plan arrives for execution, the first check should be whether the target change is already present in the working tree or recent history. `git log -- <target-file>` plus a `grep` for the target symbol across the repo quickly distinguishes "already done" from "needs doing," avoiding redundant edits.
- The plan checkbox sync discipline (`check_plan_checkboxes.py`) is valuable even when the implementation predated the plan — it makes the plan file a durable record that a fresh session can trust.
