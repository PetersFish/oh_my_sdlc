# Learnings

- When extracting functions that call other functions in the same module, ensure ALL dependencies are moved together or properly imported.
- Python's `sys.path.insert` at module level in workflow.py is the cleanest way to make the sibling package importable.
- Lazy imports (inside functions) can break circular dependency cycles for modules that need each other.
