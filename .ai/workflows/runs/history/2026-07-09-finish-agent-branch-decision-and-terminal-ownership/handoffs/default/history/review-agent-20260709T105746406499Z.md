## Issues

1. `cmd_after_dispatch` accepts a successful lightweight-flow `finish-agent` result even when expected Superpowers design artifacts are missing and `_archive_lightweight_superpowers_artifacts()` moves nothing. The helper records skipped sources internally, but the caller ignores `archive_result["skipped"]`, leaves `archive_action_completed: true` intact, and allows `complete-phase` to pass. 2. The archive helper only derives destinations from explicit `source_design_artifact_paths`/`archived_design_artifact_paths` or from structured `context.design_artifact_paths[]` entries. It does not implement the deterministic slug/date fallback required by Task 8 / Spec Decision 11, so a run with only a plan primary path and a matching spec file can complete while the matching spec remains in `docs/superpowers/specs/`.

## Learnings

- The new tests cover the happy path where finish-agent reports valid source/destination paths, collision behavior, and a blocked finish-agent missing-artifacts result. They do not cover the runtime path where finish-agent returns success but the runtime archive move cannot find or derive the expected artifacts.
- `_archive_lightweight_superpowers_artifacts()` already returns enough information (`moved` and `skipped`) to let `cmd_after_dispatch` enforce the missing-artifact contract; the issue is that the caller currently discards `skipped` and does not validate that expected plan/spec moves occurred.

## Suggestions

- Add a behavior test where `finish-agent` returns success with expected lightweight archive source paths that do not exist; assert `after-dispatch` blocks or marks `archive_action_completed: false` with `missing_lightweight_archive_artifacts` rather than allowing phase completion.
- Add a behavior test where only `primary_design_path` points to a plan and a same-slug spec exists; assert both plan and spec are moved using the deterministic fallback.
- Update `cmd_after_dispatch` to treat skipped expected artifacts as a blocker or false archive evidence, and implement the documented slug/date fallback for matching spec/plan artifacts.
