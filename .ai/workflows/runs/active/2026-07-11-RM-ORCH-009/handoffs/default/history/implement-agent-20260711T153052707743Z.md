# Suggestions

- When an implement-agent session is cancelled mid-work, the handoff should always reflect the latest tasks.md checkbox state, not an earlier mental model of progress.
- Consider adding a validation script that checks OpenSpec tasks.md checkbox completeness against the `openspec status` JSON output to catch handoff/reporting drift.
