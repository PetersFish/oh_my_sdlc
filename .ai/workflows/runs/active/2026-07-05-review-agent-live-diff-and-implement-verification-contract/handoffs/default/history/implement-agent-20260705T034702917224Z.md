The test asserted the exact phrase "Do not use CodeGraph as the source of truth for uncommitted changes". Aligned the prompt to the test's expected casing to avoid weakening the test.

## Suggestions

- Future plan specs that prescribe exact prompt wording should include the exact test-asserted phrase verbatim, so implementers do not have to reconcile casing differences between the plan and the test.
- Consider adding `git ls-files*` to the implement-agent bash allow list so implement-agent can fully satisfy its own change-set handoff contract (currently it relies on `git status --short` for untracked discovery, which is sufficient but less direct than `git ls-files --others --exclude-standard`).
