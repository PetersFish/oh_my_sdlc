# Academic Clean

Use for algorithm flowcharts, data structures, state machines, derivations, and dense technical diagrams where clarity matters most.

Keywords: rational, clear, restrained, high information density.

## Colors

| Role | Color | Usage |
|---|---:|---|
| Background | `#FAFAF7` | Page or canvas background |
| Primary node | `#2F5D8C` | Main flow, core state |
| Secondary node | `#7B8DA6` | Supporting steps, intermediate states |
| Emphasis node | `#E67E22` | Key decision, turning point |
| Success node | `#2E8B57` | Output, success state |
| Error node | `#C0392B` | Exception path, error handling |
| Edge | `#4A4A4A` | Main connectors, classic arrow |
| Text | `#222222` | Default text |

## Style

- Border: `1.5px`
- Radius: `8px`
- Shadow: off
- Opacity: `100%`
- Font: JetBrains Mono, Inter, or IBM Plex Sans
- Edge width: `2px`
- Arrow: classic or block, used consistently
